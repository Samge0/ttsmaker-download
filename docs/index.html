3

创建环境

conda create -n ttsmaker-download python=3.10.13 -y

安装依赖

常见问题

使用过程中的常见疑问解答

如何配置 ChromeDriver 路径？

复制 config.demo.py 为 config.py，然后在 config.py 文件中设置您的 ChromeDriver 可执行文件的完整路径。确保 ChromeDriver 版本与您的 Chrome 浏览器版本匹配。

crawler.py 和 crawler_js.py 有什么区别？

crawler.py 使用传统的 Selenium 方法，而 crawler_js.py 使用 JavaScript 执行方式。两种方法都能达到相同的效果，您可以根据自己的需求选择使用。

提取的音频数据可以用于其他 TTS 模型吗？

是的，提取的音频数据是通用的音频格式，可以用于各种 TTS 模型的训练和测试，不仅限于 F5 TTS。

如何确保音频提取的质量？

工具会从 ttsmaker.cn 平台提取高质量的音频文件。建议在稳定网络环境下运行，并检查下载的音频文件完整性。

是否支持批量下载音频？

是的，工具支持批量下载。您可以访问项目的 GitHub Releases 页面下载预打包的示例音频集合 results.zip。
